# 🎯 Quiz Telegram Bot

Многофункциональный Telegram-бот для создания, проведения и анализа квизов.

Бот позволяет создавать тесты с настраиваемым количеством вопросов, делиться ими по ссылке, отслеживать результаты пользователей и управлять ботом через удобную административную панель.

---

# Возможности

## Для пользователей

- 📝 Прохождение квизов
- 🎯 Выбор правильного ответа из нескольких вариантов
- 🔗 Возможность проходить квизы по ссылке
- 📊 Просмотр своей статистики
- 🖼️ Каждый вопрос может содержать собственное изображение
- ⚡ Быстрое прохождение без регистрации

---

## Для создателя квиза

- ➕ Создание новых квизов
- 🔢 Настройка любого количества вопросов
- ✅ Выбор правильного ответа для каждого вопроса
- 🔗 Генерация ссылки для отправки друзьям
- 📈 Просмотр статистики прохождения
- 👥 Количество участников
- 📊 Анализ правильных и неправильных ответов

---

## Административная панель

Администратор имеет расширенные возможности управления ботом:

- 👤 Просмотр общего количества пользователей
- 📈 Просмотр статистики использования
- 🔧 Включение режима технического обслуживания
- 📋 Управление системой и настройками проекта
- ⚙️ Дополнительные административные функции

# Настройка конфигурации

Пр## Конфигурация

Проект использует два файла конфигурации.

### `.env`

Содержит все секретные данные проекта:

- токен Telegram-бота;
- строку подключения к PostgreSQL;
- ключи платёжных систем;
- другие чувствительные данные.

Файл `.env` **не должен публиковаться** и должен быть добавлен в `.gitignore`.

### `config.toml`

Содержит основные настройки приложения, не являющиеся секретными.

Например:

- режим работы;
- параметры бота;
- настройки проекта;
- различные лимиты и конфигурацию.

Во время запуска приложение загружает настройки из `config.toml`, а секретные данные — из `.env`.
